# LRU Cache in 3D Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `lru-cache.html`, a single offline file that teaches how an LRU cache works through a six-chapter 3D guided tour followed by a sandbox.

**Architecture:** A pure cache model (`src/lru.js`) emits a list of steps for every `get`/`put`. An animator turns each step into a timeline clip built from Three.js scene primitives. A tour runner plays chapter scripts (captions, operations, camera moves) through the animator; a thin HTML overlay provides controls and the sandbox form. esbuild bundles everything, Three.js included, into one HTML file.

**Tech Stack:** Node 22, Three.js (bundled), esbuild (dev), `node:test`. No animation library, no framework.

**Spec:** `docs/superpowers/specs/2026-10-02-lru-cache-3d-design.md`. Read it before starting any task.

## Global Constraints

- Output is one file, `lru-cache.html`, at the project root. It opens by double-click over `file://` and makes no network requests at runtime: no CDN, no web fonts, no remote textures, no Three.js loaders.
- Target: desktop Chrome, Safari, Firefox on macOS. Overlay stays readable down to 1024 px wide. No mobile layout.
- Runtime dependency: `three` only. Dev dependency: `esbuild` only. Do not add others.
- **No git.** Do not run `git init`, do not commit. Each task ends with tests and a report instead of a commit.
- All subagents (implementers and reviewers) are dispatched with `model: "opus"` (Opus 5.5).
- ES modules everywhere (`"type": "module"`). Tests are `test/*.test.js`, run with `node --test`.
- Keys and values are strings of 1 to 3 characters. Keys are case-sensitive. Sandbox capacity is 2 to 8, default 4. The tour uses capacity 3.
- All user-supplied text reaches the DOM through `textContent`, never `innerHTML`.
- On-screen teaching copy comes from `src/chapters.js` and `describeStep()` in `src/animator.js` exactly as written in this plan. Do not reword it.
- **The clip rule (scene code):** a function that returns a clip captures only its arguments. Every read or write of scene state happens inside the clip's `onStart`, `onUpdate`, or `onComplete`. The animator builds all clips for an operation before any of them runs, so a clip for `attachHead("A")` is constructed before the clip for `create("A")` has executed.
- Out of scope (do not build): code panel, sound, other eviction policies, session saving, reduced-motion mode.

## How this plan refines the spec

- The spec's `tour.js` is split into `chapters.js` (the script, as data) and `tour.js` (the runner). Sandbox validation lives in `validate.js`, and scene geometry maths in `scene/layout.js`, so both can be unit-tested without a browser.
- The spec gives play/pause and step back to the animator. Here the animator owns the queue and `restore(state)`; the tour runner owns the beat pointer and calls `restore` to step back. The behaviour the spec describes is unchanged.
- Logic modules (Tasks 1 to 5) come with complete code. Scene and overlay modules (Tasks 6 to 9) are specified by contract, visual parameters, and browser checks, with code given only for the parts other modules depend on. Their visual craft is the implementer's job; their interfaces are not negotiable.

## Review Focus

Conditions the spec implies but does not spell out, most likely first. Each is pinned by a test in the task named.

1. **Operations submitted faster than they animate.** Expected: they play in submission order and the final scene matches the model. Pinned in Task 4 (`ops enqueued together play in submission order`).
2. **Chapter jump, step back, or capacity change in the middle of an animation.** Expected: the scene snaps to the restored state, queued operations are dropped, nothing from the abandoned run is logged afterwards. Pinned in Task 4 (`restore mid-flight drops in-flight and queued ops`) and Task 5 (`stepBack ...`, `jumping to another chapter abandons the old run`).
3. **Touching the entry already at HEAD.** Expected: no detach or re-attach, it still counts as a hit or an update. Pinned in Task 2 and Task 4 (`get of the head key plays lookup and result only`).
4. **Odd sandbox input:** surrounding spaces, `<b>`, emoji, `a` versus `A`, over-long text. Expected: trimmed, length counted in code points, case-sensitive, shown as literal text. Pinned in Task 4 (`validateOp` tests) and the Task 9 browser check.
5. **A very long frame** (tab was hidden, then shown). Expected: a sequence still runs every callback once, in order, and a clip always completes before its successor starts. Pinned in Task 3 (`one huge update ...`, `a clip completes before the next one starts ...`).

Also pinned, lower risk: two keys hashing to the same wall bucket (Task 6, `assignBucket probes past occupied cells`).

## Shared interfaces

Every task relies on these names. They are repeated in each task's Interfaces block.

**Clip:** `{ duration: number, advance(time: number): void }`. `advance` is called with non-decreasing local time in seconds; `Infinity` means "finish now".

**Step** (emitted by `lru.js`): one of
`{type:'lookup', key, found}`, `{type:'detach', key}`, `{type:'attachHead', key}`, `{type:'create', key, value}`, `{type:'update', key, oldValue, value}`, `{type:'evict', key}`, `{type:'mapSet', key}`, `{type:'mapDelete', key}`, `{type:'result', kind, value?}` with `kind` in `'hit' | 'miss' | 'inserted' | 'updated'`.

**Snapshot:** `{ capacity: number, entries: [{key, value}] }`, entries ordered HEAD to TAIL.

**Op:** `{type:'get', key}` or `{type:'put', key, value}`.

**Scene API** (returned by `createScene(canvas)`):

| Member | Kind | Meaning |
|---|---|---|
| `start(tick)` | instant | Start the frame loop; calls `tick(dt)` each frame with `dt` in seconds, clamped to 0.1 |
| `syncTo(snapshot)` | instant | Rebuild the scene to match the snapshot exactly; remove all in-flight effects |
| `setInternals(alpha)` | instant | Opacity 0..1 of hash-map wall, beams, and link tubes |
| `setView(name)` | instant | Jump the camera to a named view |
| `cameraTo(name, duration)` | clip | Glide the camera to a named view |
| `fadeInternals(alpha, duration)` | clip | Fade internals opacity |
| `lookup(key, found)` | clip | Pulse from the key's bucket to its slab, or to an empty bucket that flashes red |
| `detach(key)` | clip | Slab lifts out of the row; neighbours link to each other |
| `attachHead(key)` | clip | Slab flies to HEAD; others shift; colours re-settle |
| `create(key, value)` | clip | New slab materialises, lifted above HEAD |
| `update(key, value)` | clip | Value text morphs |
| `evict(key)` | clip | Slab shatters into particles |
| `mapSet(key)` / `mapDelete(key)` | clip | Bucket lights up with a beam / goes dark |
| `result(kind, key)` | clip | Hit, insert, update: slab flares. Miss: the row flashes red |
| `scan({onVisit})` | clip | Highlight visits each slab HEAD to TAIL, calling `onVisit(n)` with n = 1, 2, ... |

View names: `'wide' | 'row' | 'map' | 'head' | 'tail'`.

## Visual brief (Tasks 6 to 9)

The bar is "jaw-dropping": this should look like a title sequence, not a diagram. The contracts above are fixed; the craft is the implementer's. Minimum direction:

- **Palette.** Background `#05060d`. Recency ramp: hot `#c8f7ff`, mid `#4aa8ff`, cold `#5b2a9d`. Hash map and beams: gold `#ffc46b`. `next` tubes `#7de3ff`, `prev` tubes `#b48cff`. Miss `#ff3b5c`. Eviction shards start at the slab's colour and burn to ember `#ff7a3c`.

- **Motion.** Nothing teleports and nothing moves linearly. Slabs fly in arcs, settle with a slight overshoot, and bob gently when idle. The camera drifts a little even at rest.

- **Type (overlay).** Captions in `"Avenir Next", "Helvetica Neue", system-ui, sans-serif`; keys, values, calls, and the log in `"SF Mono", ui-monospace, Menlo, monospace`. System fonts only.

- [ ] **Step 5: Write `build.mjs`**

```js
import { build } from 'esbuild';
import { readFile, writeFile } from 'node:fs/promises';
import { fileURLToPath, pathToFileURL } from 'node:url';

const at = (relative) => fileURLToPath(new URL(relative, import.meta.url));

export async function buildPage() {
  const result = await build({
    entryPoints: [at('src/main.js')],
    bundle: true,
    format: 'iife',
    minify: true,
    target: 'es2022',
    legalComments: 'none',
    write: false,
  });
  // A literal "</script" inside the bundle would end the inline script tag.
  const js = result.outputFiles[0].text.replaceAll('</script', '<\\/script');
  const css = await readFile(at('src/styles.css'), 'utf8');
  const template = await readFile(at('src/index.html'), 'utf8');
  // Function replacers: a string replacement would interpret "$&" and "$1" inside the bundle.
  const html = template
    .replace('/*__CSS__*/', () => css)
    .replace('/*__JS__*/', () => js);
  const path = at('lru-cache.html');
  await writeFile(path, html);
  return { path, bytes: Buffer.byteLength(html) };
}

if (import.meta.url === pathToFileURL(process.argv[1]).href) {
  const { path, bytes } = await buildPage();
  console.log(`built ${path} (${Math.round(bytes / 1024)} KB)`);
}
```

### Task 2: LRU cache model

**Files:**
- Create: `src/lru.js`
- Test: `test/lru.test.js`

**Interfaces:**
- Consumes: nothing.
- Produces:
  - `new LRUCache(capacity)`: throws `RangeError` unless `capacity` is an integer of 1 or more.
  - `cache.capacity`, `cache.size`: numbers.
  - `cache.get(key): { value: string | undefined, steps: Step[] }`
  - `cache.put(key, value): { steps: Step[] }`
  - `cache.snapshot(): Snapshot`
  - `LRUCache.fromSnapshot(snapshot): LRUCache`
  - Step lists, exactly:
    - get miss: `lookup(found:false)`, `result(miss)`
    - get hit, key not at head: `lookup(found:true)`, `detach`, `attachHead`, `result(hit, value)`
    - get hit, key at head: `lookup(found:true)`, `result(hit, value)`
    - put new key, space free: `lookup(found:false)`, `create`, `attachHead`, `mapSet`, `result(inserted)`
    - put new key, full: `lookup(found:false)`, `evict(tail key)`, `mapDelete(tail key)`, `create`, `attachHead`, `mapSet`, `result(inserted)`
    - put existing key not at head: `lookup(found:true)`, `update`, `detach`, `attachHead`, `result(updated, value)`
    - put existing key at head: `lookup(found:true)`, `update`, `result(updated, value)`

`src/lru.js`:

```js
class Node {
  constructor(key, value) {
    this.key = key;
    this.value = value;
    this.prev = null;
    this.next = null;
  }
}

// Hash map for O(1) lookup, doubly linked list for O(1) reordering.
// head.next is the most recently used entry; tail.prev is the least.
export class LRUCache {
  #capacity;
  #map = new Map();
  #head = new Node(null, null);
  #tail = new Node(null, null);

  constructor(capacity) {
    if (!Number.isInteger(capacity) || capacity < 1) {
      throw new RangeError(`capacity must be a positive integer, got ${capacity}`);
    }
    this.#capacity = capacity;
    this.#head.next = this.#tail;
    this.#tail.prev = this.#head;
  }

  get capacity() { return this.#capacity; }
  get size() { return this.#map.size; }

  get(key) {
    const node = this.#map.get(key);
    if (!node) {
      return {
        value: undefined,
        steps: [{ type: 'lookup', key, found: false }, { type: 'result', kind: 'miss' }],
      };
    }
    const steps = [{ type: 'lookup', key, found: true }];
    this.#touch(node, steps);
    steps.push({ type: 'result', kind: 'hit', value: node.value });
    return { value: node.value, steps };
  }

  put(key, value) {
    const existing = this.#map.get(key);
    if (existing) {
      const steps = [
        { type: 'lookup', key, found: true },
        { type: 'update', key, oldValue: existing.value, value },
      ];
      existing.value = value;
      this.#touch(existing, steps);
      steps.push({ type: 'result', kind: 'updated', value });
      return { steps };
    }
    const steps = [{ type: 'lookup', key, found: false }];
    if (this.#map.size >= this.#capacity) {
      const victim = this.#tail.prev;
      this.#unlink(victim);
      this.#map.delete(victim.key);
      steps.push({ type: 'evict', key: victim.key }, { type: 'mapDelete', key: victim.key });
    }
    const node = new Node(key, value);
    this.#linkAtHead(node);
    this.#map.set(key, node);
    steps.push(
      { type: 'create', key, value },
      { type: 'attachHead', key },
      { type: 'mapSet', key },
      { type: 'result', kind: 'inserted' },
    );
    return { steps };
  }

  snapshot() {
    const entries = [];
    for (let node = this.#head.next; node !== this.#tail; node = node.next) {
      entries.push({ key: node.key, value: node.value });
    }
    return { capacity: this.#capacity, entries };
  }

  static fromSnapshot({ capacity, entries }) {
    const cache = new LRUCache(capacity);
    if (entries.length > capacity) {
      throw new RangeError('snapshot has more entries than capacity');
    }
    // Insert tail-first so the first entry ends up at head.
    for (let i = entries.length - 1; i >= 0; i--) {
      const node = new Node(entries[i].key, entries[i].value);
      cache.#linkAtHead(node);
      cache.#map.set(node.key, node);
    }
    return cache;
  }

  #touch(node, steps) {
    if (this.#head.next === node) return;
    this.#unlink(node);
    this.#linkAtHead(node);
    steps.push({ type: 'detach', key: node.key }, { type: 'attachHead', key: node.key });
  }

  #unlink(node) {
    node.prev.next = node.next;
    node.next.prev = node.prev;
    node.prev = null;
    node.next = null;
  }

  #linkAtHead(node) {
    node.next = this.#head.next;
    node.prev = this.#head;
    this.#head.next.prev = node;
    this.#head.next = node;
  }
}
```

```js
export const ease = {
  linear: (t) => t,
  inCubic: (t) => t * t * t,
  outCubic: (t) => 1 - (1 - t) ** 3,
  inOutCubic: (t) => (t < 0.5 ? 4 * t * t * t : 1 - (-2 * t + 2) ** 3 / 2),
  outBack: (t) => 1 + 2.70158 * (t - 1) ** 3 + 1.70158 * (t - 1) ** 2,
};

// A clip is { duration, advance(time) }. advance receives non-decreasing local
// time in seconds; Infinity means "finish now".
export function tween({ duration, ease: easing = ease.inOutCubic, onStart, onUpdate, onComplete }) {
  let started = false;
  let done = false;
  return {
    duration,
    advance(time) {
      if (done) return;
      if (!started) {
        started = true;
        onStart?.();
      }
      const progress = duration <= 0 ? 1 : Math.min(time / duration, 1);
      onUpdate?.(easing(progress));
      if (progress >= 1) {
        done = true;
        onComplete?.();
      }
    },
  };
}

export const wait = (duration) => tween({ duration });
export const call = (fn) => tween({ duration: 0, onComplete: fn });

export function seq(...clips) {
  const offsets = [];
  let total = 0;
  for (const clip of clips) {
    offsets.push(total);
    total += clip.duration;
  }
  return {
    duration: total,
    advance(time) {
      for (let i = 0; i < clips.length; i++) {
        if (time < offsets[i]) break;
        // Once the next clip is due, force this one to finish. Subtracting
        // offsets can round to just under the duration and leave it at 0.999.
        const end = i + 1 < clips.length ? offsets[i + 1] : total;
        clips[i].advance(time >= end ? Infinity : time - offsets[i]);
      }
    },
  };
}

export function par(...clips) {
  return {
    duration: clips.reduce((longest, clip) => Math.max(longest, clip.duration), 0),
    advance(time) {
      for (const clip of clips) clip.advance(time);
    },
  };
}

export function rate(clip, factor) {
  return {
    duration: clip.duration / factor,
    advance(time) {
      clip.advance(time * factor);
    },
  };
}

export class Player {
  speed = 1;
  paused = false;
  #active = [];

  play(clip) {
    return new Promise((resolve) => {
      this.#active.push({ clip, time: 0, resolve });
    });
  }

  update(dt) {
    if (this.paused) return;
    const step = dt * this.speed;
    for (const item of [...this.#active]) {
      // A callback earlier in this loop may have cancelled everything.
      if (!this.#active.includes(item)) continue;
      item.time += step;
      const finished = item.time >= item.clip.duration;
      item.clip.advance(finished ? Infinity : item.time);
      if (!finished) continue;
      const index = this.#active.indexOf(item);
      if (index !== -1) {
        this.#active.splice(index, 1);
        item.resolve(true);
      }
    }
  }

  cancelAll() {
    const cancelled = this.#active;
    this.#active = [];
    for (const item of cancelled) item.resolve(false);
  }

  get busy() {
    return this.#active.length > 0;
  }
}
```

```js
export const MAX_LENGTH = 3;
export const MIN_CAPACITY = 2;
export const MAX_CAPACITY = 8;

function check(raw, field, label) {
  const text = String(raw ?? '').trim();
  if (text.length === 0) return { ok: false, field, message: `Enter a ${label}.` };
  if ([...text].length > MAX_LENGTH) {
    return { ok: false, field, message: `A ${label} is at most ${MAX_LENGTH} characters.` };
  }
  return { ok: true, text };
}

export function validateOp({ type, key, value }) {
  const checkedKey = check(key, 'key', 'key');
  if (!checkedKey.ok) return checkedKey;
  if (type === 'get') return { ok: true, op: { type: 'get', key: checkedKey.text } };
  const checkedValue = check(value, 'value', 'value');
  if (!checkedValue.ok) return checkedValue;
  return { ok: true, op: { type: 'put', key: checkedKey.text, value: checkedValue.text } };
}

export function validateCapacity(raw) {
  if (raw === null || raw === '') return null;
  const n = Number(raw);
  return Number.isInteger(n) && n >= MIN_CAPACITY && n <= MAX_CAPACITY ? n : null;
}
```

```js
import { LRUCache } from './lru.js';
import { seq, call, wait, rate } from './timeline.js';

const ZERO_STATS = { hits: 0, misses: 0, evictions: 0 };

export function formatCall(op) {
  return op.type === 'get' ? `get(${op.key})` : `put(${op.key}, ${op.value})`;
}

export function describeStep(step) {
  switch (step.type) {
    case 'lookup':
      return step.found
        ? `Hash map: ${step.key} found in one hop.`
        : `Hash map: no entry for ${step.key}.`;
    case 'detach':
      return `Unlink ${step.key}: its two neighbours now point at each other.`;
    case 'attachHead':
      return `Link ${step.key} in at HEAD. It is now the most recently used.`;
    case 'create':
      return `Create an entry for ${step.key} = ${step.value}.`;
    case 'update':
      return `Overwrite the value: ${step.oldValue} becomes ${step.value}.`;
    case 'evict':
      return `The cache is full. Evict ${step.key}, the least recently used, from TAIL.`;
    case 'mapSet':
      return `Add ${step.key} to the hash map, pointing at its entry.`;
    case 'mapDelete':
      return `Remove ${step.key} from the hash map.`;
    case 'result':
      if (step.kind === 'hit') return `Hit: return ${step.value}. Every step was O(1).`;
      if (step.kind === 'miss') return 'Miss: there is nothing to return.';
      if (step.kind === 'updated') return 'Updated. Every step was O(1).';
      return 'Inserted. Every step was O(1).';
    default:
      throw new Error(`unknown step type: ${step.type}`);
  }
}

export function summarize(op, steps) {
  const result = steps.find((step) => step.type === 'result');
  const evicted = steps.find((step) => step.type === 'evict')?.key ?? null;
  let outcome;
  if (result.kind === 'hit') outcome = `hit: ${result.value}`;
  else if (result.kind === 'inserted' && evicted !== null) outcome = `inserted, evicted ${evicted}`;
  else outcome = result.kind;
  return { call: formatCall(op), kind: result.kind, outcome, evicted };
}

function sceneClip(step, op, scene) {
  switch (step.type) {
    case 'lookup': return scene.lookup(step.key, step.found);
    case 'detach': return scene.detach(step.key);
    case 'attachHead': return scene.attachHead(step.key);
    case 'create': return scene.create(step.key, step.value);
    case 'update': return scene.update(step.key, step.value);
    case 'evict': return scene.evict(step.key);
    case 'mapSet': return scene.mapSet(step.key);
    case 'mapDelete': return scene.mapDelete(step.key);
    case 'result': return scene.result(step.kind, op.key);
    default: throw new Error(`unknown step type: ${step.type}`);
  }
}

export function stepsToClip(op, steps, scene, { stepGap = 0, onStep, rate: factor = 1 } = {}) {
  const clips = [];
  steps.forEach((step, index) => {
    if (onStep) clips.push(call(() => onStep(step, index)));
    clips.push(sceneClip(step, op, scene));
    if (stepGap > 0) clips.push(wait(stepGap));
  });
  const clip = seq(...clips);
  return factor === 1 ? clip : rate(clip, factor);
}

export function createAnimator({ scene, player, capacity = 4, onLog = () => {}, onStats = () => {} }) {
  let cache = new LRUCache(capacity);
  let stats = { ...ZERO_STATS };
  let queue = Promise.resolve();
  // Bumped by restore(); an op from an older generation is abandoned.
  let generation = 0;

  scene.syncTo(cache.snapshot());

  function enqueue(op, opts = {}) {
    const born = generation;
    const job = queue.then(async () => {
      if (born !== generation) return { completed: false };
      const { steps } = op.type === 'get' ? cache.get(op.key) : cache.put(op.key, op.value);
      const summary = summarize(op, steps);
      await player.play(stepsToClip(op, steps, scene, opts));
      if (born !== generation) return { completed: false, steps, summary };
      if (summary.kind === 'hit') stats.hits++;
      if (summary.kind === 'miss') stats.misses++;
      if (summary.evicted !== null) stats.evictions++;
      onLog(summary);
      onStats({ ...stats });
      return { completed: true, steps, summary };
    });
    queue = job.catch(() => {});
    return job;
  }

  function state() {
    return { snapshot: cache.snapshot(), stats: { ...stats } };
  }

  function restore(next) {
    generation++;
    player.cancelAll();
    cache = LRUCache.fromSnapshot(next.snapshot);
    stats = { ...next.stats };
    scene.syncTo(cache.snapshot());
    onStats({ ...stats });
  }

  function reset(nextCapacity) {
    restore({ snapshot: { capacity: nextCapacity, entries: [] }, stats: ZERO_STATS });
  }

  return { enqueue, state, restore, reset };
}
```

```js
import { wait, par } from './timeline.js';
import { describeStep, formatCall } from './animator.js';

const ZERO_STATS = { hits: 0, misses: 0, evictions: 0 };
const SLOW_STEP_GAP = 0.9;

export function createTour({ chapters, animator, scene, player, ui, onEnd = () => {} }) {
  let chapterIndex = 0;
  let beatIndex = 0;
  // Each run() claims a new id; a run whose id is stale stops at its next await.
  let runId = 0;
  // states[i] is what the world looked like just before beat i started.
  let states = [];
  let internals = false;
  let view = 'wide';
  let playing = false;
  let stopAfterOp = false;

  // Resolves the gate in run() when playback resumes.
  let wake = null;

  function setPlaying(value) {
    playing = value;
    player.paused = !value;
    ui.setPlaying(value);
    if (value && wake) {
      wake();
      wake = null;
    }
  }

  function whenPlaying() {
    return new Promise((resolve) => { wake = resolve; });
  }

  function clearTransient() {
    ui.showCard(null);
    ui.setCounter(null);
    ui.setOp(null);
  }

  function start(index = 0, { paused = false } = {}) {
    const chapter = chapters[index];
    chapterIndex = index;
    beatIndex = 0;
    states = [];
    stopAfterOp = false;
    animator.restore({ snapshot: chapter.initial, stats: ZERO_STATS });
    internals = chapter.internals;
    view = 'wide';
    scene.setInternals(internals ? 1 : 0);
    scene.setView(view);
    clearTransient();
    ui.clearLog();
    ui.setCaption('');
    ui.setChapter(index, chapter.title, chapters.length);
    setPlaying(!paused);
    run(0);
  }

  async function run(fromBeat) {
    const id = ++runId;
    const alive = () => id === runId;
    const { beats } = chapters[chapterIndex];
    for (let i = fromBeat; i < beats.length; i++) {
      beatIndex = i;
      // While paused, do not start the next beat: an op beat would change the
      // model ahead of what is on screen.
      if (!playing) {
        await whenPlaying();
        if (!alive()) return;
      }
      states[i] = { ...animator.state(), internals, view };
      await playBeat(beats[i], alive);
      if (!alive()) return;
      if (beats[i].type === 'op' && stopAfterOp) {
        stopAfterOp = false;
        setPlaying(false);
      }
    }
    if (chapterIndex + 1 < chapters.length) start(chapterIndex + 1);
    else onEnd();
  }

  async function playBeat(beat, alive) {
    if (beat.caption) ui.setCaption(beat.caption);
    switch (beat.type) {
      case 'caption':
        ui.setOp(null);
        ui.setCaption(beat.text);
        await player.play(wait(beat.hold));
        return;
      case 'op': {
        ui.setOp(formatCall(beat.op));
        let opts = {};
        if (beat.pace === 'slow') {
          opts = {
            stepGap: SLOW_STEP_GAP,
            onStep: (step) => { if (alive()) ui.setCaption(describeStep(step)); },
          };
        } else if (beat.pace === 'fast') {
          opts = { rate: 2 };
        }
        await animator.enqueue(beat.op, opts);
        if (!alive()) return;
        await player.play(wait(beat.pace === 'fast' ? 0.15 : 0.6));
        return;
      }
      case 'camera':
        view = beat.view;
        await player.play(par(scene.cameraTo(beat.view, beat.duration ?? 1.6), wait(beat.hold ?? 0)));
        return;
      case 'internals':
        internals = beat.visible;
        await player.play(par(scene.fadeInternals(beat.visible ? 1 : 0, 1.4), wait(beat.hold ?? 0)));
        return;
      case 'scan':
        ui.setCounter('comparisons', 0);
        await player.play(scene.scan({
          onVisit: (n) => { if (alive()) ui.setCounter('comparisons', n); },
        }));
        if (!alive()) return;
        // The counter stays up for the captions that follow; start() clears it.
        await player.play(wait(beat.hold ?? 1.5));
        return;
      case 'card':
        ui.setOp(null);
        ui.showCard({ title: beat.title, lines: beat.lines });
        await player.play(wait(beat.hold));
        if (alive()) ui.showCard(null);
        return;
      default:
        throw new Error(`unknown beat type: ${beat.type}`);
    }
  }

  function togglePlaying() {
    stopAfterOp = false;
    setPlaying(!playing);
  }

  function stepForward() {
    stopAfterOp = true;
    setPlaying(true);
  }

  function stepBack() {
    if (beatIndex === 0) {
      start(Math.max(chapterIndex - 1, 0), { paused: true });
      return;
    }
    const { beats } = chapters[chapterIndex];
    let target = beatIndex - 1;
    while (target > 0 && beats[target].type !== 'op') target--;
    const state = states[target];
    animator.restore(state);
    internals = state.internals;
    view = state.view;
    scene.setInternals(internals ? 1 : 0);
    scene.setView(view);
    clearTransient();
    ui.setCaption('');
    ui.truncateLog(beats.slice(0, target).filter((beat) => beat.type === 'op').length);
    stopAfterOp = false;
    setPlaying(false);
    run(target);
  }

  function stop() {
    runId++;
    stopAfterOp = false;
    clearTransient();
  }

  return {
    start,
    togglePlaying,
    stepForward,
    stepBack,
    stop,
    position: () => ({ chapter: chapterIndex, beat: beatIndex }),
    isPlaying: () => playing,
  };
}
```

```js
// Pure layout maths. No three.js import, so it runs under node --test.
export const SLOT_SPACING = 2.2;
export const BUCKET_COUNT = 12;
export const LIFT = 2.0;

const BUCKET_COLUMNS = 6;
const WALL_Z = -4;

export function slotX(index, capacity) {
  return (index - (capacity - 1) / 2) * SLOT_SPACING;
}

export function recencyT(index, capacity) {
  return capacity <= 1 ? 0 : index / (capacity - 1);
}

export function homeBucket(key) {
  let hash = 0;
  for (const ch of String(key)) hash = (hash * 31 + ch.codePointAt(0)) >>> 0;
  return hash % BUCKET_COUNT;
}

export function assignBucket(key, occupied) {
  let index = homeBucket(key);
  for (let probes = 0; probes < BUCKET_COUNT; probes++) {
    if (!occupied.has(index)) return index;
    index = (index + 1) % BUCKET_COUNT;
  }
  return -1;
}

export function bucketPosition(index) {
  const column = index % BUCKET_COLUMNS;
  const row = Math.floor(index / BUCKET_COLUMNS);
  return { x: (column - (BUCKET_COLUMNS - 1) / 2) * 1.6, y: 4.6 - row * 1.2, z: WALL_Z };
}

export function viewFor(name, capacity) {
  const wideZ = Math.max(13, capacity * 2.6 + 3);
  switch (name) {
    case 'wide': return { position: [0, 3.4, wideZ], target: [0, 1.6, -1.5] };
    case 'row': return { position: [0, 1.6, wideZ * 0.75], target: [0, 0.3, 0] };
    case 'map': return { position: [0, 4.6, 8.5], target: [0, 3.9, WALL_Z] };
    case 'head': return { position: [slotX(0, capacity) - 1.5, 1.8, 7], target: [slotX(0, capacity), 0.3, 0] };
    case 'tail': {
      const x = slotX(capacity - 1, capacity);
      return { position: [x + 1.5, 1.8, 7], target: [x, 0.3, 0] };
    }
    default: throw new Error(`unknown view: ${name}`);
  }
}
```

```js
const updaters = [];
function addUpdater(fn) { updaters.push(fn); }

function start(tick) {
  let last = performance.now();
  let elapsed = 0;
  renderer.setAnimationLoop((now) => {
    // Clamp: after a hidden tab, one frame can report many seconds.
    const dt = Math.min((now - last) / 1000, 0.1);
    last = now;
    elapsed += dt;
    tick(dt);
    for (const fn of updaters) fn(dt, elapsed);
    controls.update();
    composer.render();
  });
}

function setView({ position, target }) {
  camera.position.set(...position);
  controls.target.set(...target);
  controls.update();
}

// getView is called when the clip starts, not when it is built (the clip rule).
function cameraClip(getView, duration) {
  const fromPosition = new THREE.Vector3();
  const fromTarget = new THREE.Vector3();
  const toPosition = new THREE.Vector3();
  const toTarget = new THREE.Vector3();
  return tween({
    duration,
    ease: ease.inOutCubic,
    onStart() {
      const view = getView();
      fromPosition.copy(camera.position);
      fromTarget.copy(controls.target);
      toPosition.set(...view.position);
      toTarget.set(...view.target);
    },
    onUpdate(p) {
      camera.position.lerpVectors(fromPosition, toPosition, p);
      controls.target.lerpVectors(fromTarget, toTarget, p);
    },
  });
}
```

**What to build**

Layout: slab centres sit at `(slotX(i, capacity), 0, 0)`. A lifted slab is at `y = LIFT`.

- **Slab.** A rounded box about 1.5 wide, 2.0 tall, 0.35 deep (`RoundedBoxGeometry` from `three/addons/geometries/RoundedBoxGeometry.js`), emissive and slightly translucent, with brighter edge lines, so it reads as a lit crystal under bloom. On the front face: the key, large; below it the value, smaller. Both are `createLabel` planes. Give each slab an inner group for the idle bob (a few centimetres, phase offset per slab) so the bob adds to, and never fights, the tweened position on the outer group.
- **Recency colour.** A slab's colour and emissive intensity come from `recencyT(index, capacity)`: 0 maps to hot `#c8f7ff` at high intensity, 0.5 to mid `#4aa8ff`, 1 to cold `#5b2a9d` at low intensity. A lifted slab keeps the colour it had.
- **Ghosts.** One faint outline per slot, for all `capacity` slots, always present. Slabs sit inside them; an empty slot shows only its ghost.
- **Markers.** `HEAD` and `TAIL` labels on small posts just outside the first and last slot.

Clips (all state changes inside callbacks, per the clip rule):

| Clip | Behaviour |
|---|---|
| `create(key, value)` | `onStart`: build the slab at `(slotX(0), LIFT, 0)` at scale 0, coloured hot. Tween scale to 1 with `outBack`. Not added to `order`. |
| `detach(key)` | `onStart`: remove the key from `order`. Tween the slab up to `y = LIFT` with a slight forward tilt. Other slabs do not move yet. |
| `attachHead(key)` | `onStart`: insert the key at the front of `order`; capture every slab's current position and colour. Tween every slab to its new slot and recency colour. The arriving slab travels in an arc and settles with a small overshoot; the others slide. |
| `update(key, value)` | Flip the value label closed, call `setText(value)` at the midpoint, flip it open, with a brief brightening. |
| `evict(key)` | `onStart`: remove the key from `order`, hide the slab, spawn about 120 shards at its position in the slab's colour.
```js
import { seq, wait, tween, ease } from '../timeline.js';
import { createStage } from './stage.js';
import { createSlabs } from './slabs.js';
import { createLinks } from './links.js';
import { createHashMap } from './hashmap.js';
import { viewFor } from './layout.js';

export function createScene(canvas) {
  const stage = createStage(canvas);
  const slabs = createSlabs(stage);
  const links = createLinks(stage, slabs);
  const hashmap = createHashMap(stage, slabs);
  let internalsAlpha = 0;

  function setInternals(alpha) {
    internalsAlpha = alpha;
    links.setAlpha(alpha);
    hashmap.setAlpha(alpha);
  }
  setInternals(0);

  return {
    start: (tick) => stage.start(tick),
    syncTo(snapshot) {
      slabs.syncTo(snapshot);
      hashmap.syncTo(snapshot);
      links.syncTo();
    },
    setInternals,
    setView(name) { stage.setView(viewFor(name, slabs.capacity())); },
    cameraTo: (name, duration) => stage.cameraClip(() => viewFor(name, slabs.capacity()), duration),
    fadeInternals(alpha, duration) {
      let from = 0;
      return tween({
        duration,
        ease: ease.inOutCubic,
        onStart() { from = internalsAlpha; },
        onUpdate(p) { setInternals(from + (alpha - from) * p); },
      });
    },
    lookup: (key, found) => seq(hashmap.lookup(key, found), found ? slabs.glint(key) : wait(0.2)),
    detach: (key) => slabs.detach(key),
    attachHead: (key) => slabs.attachHead(key),
    create: (key, value) => slabs.create(key, value),
    update: (key, value) => slabs.update(key, value),
    evict: (key) => slabs.evict(key),
    mapSet: (key) => hashmap.mapSet(key),
    mapDelete: (key) => hashmap.mapDelete(key),
    result: (kind, key) => slabs.result(kind, key),
    scan: (opts) => slabs.scan(opts),
  };
}
```

```js
import { Player } from './timeline.js';
import { createScene } from './scene/index.js';
import { createAnimator, describeStep, formatCall } from './animator.js';
import { createTour } from './tour.js';
import { chapters } from './chapters.js';
import { createUI } from './ui.js';
import { validateOp, validateCapacity } from './validate.js';

const TOUR_CAPACITY = 3;
const SANDBOX_CAPACITY = 4;
const SANDBOX_PROMPT = 'Your turn. Predict what a get or put will do, then run it.';

function showFatal(message) {
  const el = document.getElementById('fatal');
  el.textContent = message;
  el.hidden = false;
}
window.addEventListener('error', (e) => showFatal(`Something went wrong: ${e.message}`));
window.addEventListener('unhandledrejection', (e) => {
  showFatal(`Something went wrong: ${e.reason?.message ?? e.reason}`);
});

function boot() {
  let scene;
  try {
    scene = createScene(document.getElementById('stage'));
  } catch {
    showFatal('This page needs WebGL, and this browser has it turned off or does not support it.');
    return;
  }

  const player = new Player();
  let mode = 'tour';

  const ui = createUI({
    onPlayPause() {
      if (mode === 'tour') {
        tour.togglePlaying();
      } else {
        player.paused = !player.paused;
        ui.setPlaying(!player.paused);
      }
    },
    onStepForward() { if (mode === 'tour') tour.stepForward(); },
    onStepBack() { if (mode === 'tour') tour.stepBack(); },
    onSpeed(value) {
      player.speed = value;
      ui.setSpeed(value);
    },
    onChapter(index) { enterTour(index); },
    onMode(next) {
      if (next === 'sandbox') enterSandbox();
      else enterTour(0);
    },
    onSubmit(raw) {
      const checked = validateOp(raw);
      if (!checked.ok) {
        ui.showFieldError(checked.field, checked.message);
        return;
      }
      ui.showFieldError(null);
      // Submitting while paused would queue the op forever.
      player.paused = false;
      ui.setPlaying(true);
      const { op } = checked;
      animator.enqueue(op, {
        onStep(step, index) {
          if (index === 0) ui.setOp(formatCall(op));
          ui.setCaption(describeStep(step));
        },
      });
    },
    onCapacity(raw) {
      const capacity = validateCapacity(raw);
      if (capacity !== null) resetSandbox(capacity);
    },
    onReset() { resetSandbox(animator.state().snapshot.capacity); },
  });

  const animator = createAnimator({
    scene,
    player,
    capacity: TOUR_CAPACITY,
    onLog: (entry) => ui.log(entry),
    onStats: (stats) => ui.setStats(stats),
  });
  const tour = createTour({ chapters, animator, scene, player, ui, onEnd: enterSandbox });

  function resetSandbox(capacity) {
    animator.reset(capacity);
    scene.setInternals(1);
    scene.setView('wide');
    ui.clearLog();
    ui.setOp(null);
    ui.showFieldError(null);
    ui.setCapacity(capacity);
    ui.setCaption(SANDBOX_PROMPT);
    player.paused = false;
    ui.setPlaying(true);
  }

  function enterSandbox() {
    mode = 'sandbox';
    tour.stop();
    ui.setMode('sandbox');
    resetSandbox(SANDBOX_CAPACITY);
  }

  function enterTour(index) {
    mode = 'tour';
    ui.setMode('tour');
    tour.start(index);
  }

  // Deep links: #ch=4 starts at chapter 4, #sandbox opens the sandbox, #speed=4 sets the speed.
  const params = new URLSearchParams(location.hash.slice(1));
  const speed = Number(params.get('speed'));
  if (speed > 0 && speed <= 8) player.speed = speed;
  ui.setSpeed(player.speed);

  scene.start((dt) => player.update(dt));
  if (params.has('sandbox')) {
    enterSandbox();
  } else {
    const chapter = (Number(params.get('ch')) || 1) - 1;
    enterTour(Math.min(Math.max(chapter, 0), chapters.length - 1));
  }

  window.__lru = { scene, player, animator, tour, ui };
}

boot();
```
